# Система расчета экономии от масштаба – Бэкенд
Этот репозиторий содержит бэкенд-сервис для «Системы расчета экономии от масштаба», разработанной в рамках курсовой работы.
Система автоматизирует расчёт экономии от масштаба для производственных издержек, позволяя экономистам создавать заявки на расчёт, а сотрудникам компаний — управлять каталогом издержек и обрабатывать эти заявки.

Фронтенд (React SPA): https://github.com/NikitaK-hub/DIA-Frontend

Асинхронный сервис расчётов (Django): https://github.com/NikitaK-hub/calc-service
